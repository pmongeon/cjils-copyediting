# Canadian Journal of Information and Library Science / la Revue canadienne des sciences de l'information et de bibliothéconomie (CJILS / RCSIB)
## Editor's Handbook

This documentation is to support the editorial workflow with processes, controls, and resources for editors of the journal.
Please see the deployed website [here](https://pmongeon.github.io/cjils-copyediting/general.html) for using the handbook. <br>
